# Common Component Library

`spikes/_common/` contains reusable Manim building blocks extracted from repeated
spike lessons:

- `visual.py` keeps the canonical palette and scene background helpers.
- `components.py` keeps reusable mechanism geometry such as receiver slots,
  terminal brackets, bridge lanes, rhythm gates, time rails, mask windows, red
  pulses, neutral clusters, and solid slabs.
- `runner.py` keeps reusable rendering, promotion, and GIF conversion helpers.

The documentation demos are generated by:

```powershell
uv run --script spikes/component-library-demos/main.py --quality low
```

The reproducible render outputs are stored under
`videos/component-library-demos/components/<component>/`. The doc-ready GIFs are
copied to `.specs/assets/component-demos/`.
